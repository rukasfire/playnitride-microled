## 重點點點 (TL;DR)

- 錼創是 MicroLED 同業中的「**技術選項股**」——縱深型全製程 IP 勝過橫向件數
- **商業化靠三星 + 友達兩條大腿撐住**，但缺乏跨國訴訟實戰
- 公司 2025/05 法說確認的是 **8"/12" Epi、COW、CoC 設備投資**，未公開指明 GaN-on-Si；網站已把推論與事實分開
- 錼創與 Brillink 已宣布以**綠光 MicroLED + GeSi APD + 2D-AVC**開發 &lt;50 m 陣列式光互連；仍屬共同開發，不能視為 CPO 量產訂單
- TrendForce 預測 MicroLED CPO 光收發器 2030 市值約 **US$848M**、2028 下半年起放量；這是產業預測，不是錼創營收指引

## 2026/09 查證修正

- 移除「InGaN 可直接延伸至 850/940 nm」敘述。
- 移除「8"/12" GaN-on-Si 已由法說揭露」敘述，改為法說原文的設備規劃。
- 將 Brillink 的陣列式光互連與 switch 端 CPO 分開，並標示共同開發、合作方目標與研究推演。
- 將 Lumiode 定位修正為 Active TFT／近眼顯示與美國專利補強，不再直接推論為 SiPh 能力。
