## 重點點點 (TL;DR)

- 錼創是 MicroLED 同業中的「**技術選項股**」——縱深型全製程 IP 勝過橫向件數
- **商業化靠三星 + 友達兩條大腿撐住**，但缺乏跨國訴訟實戰
- **主力磊晶 = GaN-on-Sapphire (4"/6")**；8"/12" GaN-on-Si 仍在開發中（2027+ 量產）
- **CPO 路徑是下一個關鍵戰場**：TrendForce 預測 MicroLED CPO 細分市場 $848M by 2030
